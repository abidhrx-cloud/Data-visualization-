# 📊 Data Analysis Dashboard (Power BI)

## 📌 Project Overview

This project focuses on designing and developing an interactive dashboard using Power BI to analyze the dataset and extract meaningful insights for decision-making.

---

## 📂 Dataset

The dataset contains information related to:

* Usage (`husage`)
* Earnings (`husearns`)
* Education Level (`huseduc`)

---

## ⚙️ Data Preparation

The following preprocessing steps were performed:

* Handled missing values by replacing null values with appropriate defaults
* Removed unnecessary columns (e.g., `rownames`)
* Corrected data types (numeric and categorical fields)
* Cleaned and structured the dataset for analysis

---

## 📊 Dashboard Features

### 🔹 Visualizations

* **Line Chart**: Shows trend between usage and earnings
* **Bar Chart**: Compares earnings across education levels
* **Scatter Plot**: Displays relationship between usage and earnings

### 🔹 Interactivity

* Slicers (filters) for dynamic data selection
* Interactive visuals responding to user input

---

## 📈 Key Insights

* There is a positive relationship between usage and earnings
* Earnings vary across different education levels
* Data shows variation indicating possible outliers
